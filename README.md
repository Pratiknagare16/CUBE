# 🧩 Rubik’s Cube – 3D Web Game

A fully interactive 3D Rubik’s Cube built using Three.js, JavaScript, HTML and CSS.  
This project allows users to play, scramble, and solve a Rubik’s Cube in real time directly in the browser.

---

## 🚀 Features

- Real-time 3D Rubik’s Cube
- Smooth cube and layer rotations
- Mouse and touch controls
- Scramble and reset functionality
- Timer with best and average scores
- Multiple cube sizes (2×2, 3×3, 4×4, 5×5)
- Multiple color themes
- Mobile friendly UI

---

## 🧠 Technologies Used

- HTML  
- CSS  
- JavaScript  
- Three.js (WebGL)

## ▶ How to Run

1. Download or clone the repository
2. Open the project folder
3. Open `index.html` in your browser  

Or using VS Code:

- Right click on `index.html`
- Select **Open with Live Server**

---

## 🎮 How to Play

- Drag on the cube to rotate it  
- Drag on a cube face to rotate that layer  
- Double tap to start the timer  
- Use settings to change cube size, theme and scramble  
- Press reset to scramble again  

Solve the cube as fast as you can.
